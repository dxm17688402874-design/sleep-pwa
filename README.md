# Ming工具箱 (Ming Toolbox)

一个基于 HTML5、CSS3 与原生 JavaScript 开发的轻量级、零依赖、本地离线单文件工具箱应用。旨在为移动端浏览器（如华为自带浏览器、各类手机浏览器等）提供流畅、极速且数据安全的日常辅助体验。

## 🌟 核心功能特性

### 1. 🌙 作息记录模块
- **便捷睡眠监测**：首页提供一键式“开睡 / 醒来”状态切换，记录完全保存在本地，操作丝滑且无任何弹窗干扰。
- **今日与历史联动**：
  - 首页直接展示今日最新睡眠记录。
  - 历史页面配备完整月历，有记录的日期智能加亮。点击任意日期，即可联动展示当天的所有睡眠明细。
- **最新记录高亮与滑动删除**：
  - 首页及历史页面的最新一条睡眠记录会自动带有高亮渐变样式，一眼识别。
  - 列表项支持**向左滑动**呼出删除按钮，点击即可安全移除对应数据。
- **多维度时段统计**：
  - 支持按 **月份 / 年份 / 全年** 进行自由筛选统计。
  - 精准展示 **本(月/年)总睡眠时长** 与 **平均每天睡眠时长**（格式化为 `X小时X分钟`）。
  - 提供细致的四时段分布（凌晨、上午、下午、晚上）与直观的**圆角横向百分比进度条**。

### 2. 💰 账单记录模块
- **高效记账与品类管理**：
  - 支持多标签灵活分类（品类、平台、品名），并支持一键自定义添加新标签。
  - 记账页面实时计算并展示“今日总消费”，并在下方同步列出今日的消费明细列表。
- **历史账单与日历联动**：
  - 历史账单页面内置月历视图，点击任意日期可查看当天账单。
  - 日历下方和明细列表上方直观展示**所选日期的总消费金额**（例如：`2026年10月19日总消费金额：27.00元`）。
- **智能消费排行统计**：
  - 统计页面同样支持左侧月/全年、右侧年份的双向联动选择。
  - 独立展示本日总消费与选定周期的总消费。
  - 自动分析并列出金额最高/次数最多的**品类、平台与品名排行**。

### 3. 👤 个人信息与健康数据
- 自由管理身体基础数据（如身高、体重等），支持随时查看更新时间或自定义添加其他健康/生活指标。

### 4. ⚙️ 本地数据安全与管理
- 所有数据均安全存储在浏览器的 `localStorage` 中，不需要任何服务器支持。
- 提供内置的**数据管理中心**，支持一键**导出整站数据备份 (JSON)** 以及**从备份文件一键恢复**。

---

## 🛠️ 技术栈
- **前端核心**：纯原生 HTML5、CSS3（CSS Variables 现代暗黑设计风格）、Vanilla JavaScript。
- **存储方案**：HTML5 `localStorage` 本地离线持久化。
- **兼容性**：移动端优先，完美适配各类手机自带浏览器与主流移动端 Webview。

---

## 🚀 快速使用
由于本应用采用了**单文件架构（Single File Architecture）**，您只需将代码保存为一个 `index.html` 文件，然后直接用任何现代浏览器（或手机浏览器）打开即可完整体验所有功能！
