# 作息记录 PWA（最终版）

深夜紫蓝主题的离线睡眠记录工具。

## 功能
- 首页：星球按钮“开睡/起床”，自动记录开始与结束时间。
- 历史：月历标记有记录的日期，点选日期查看该日全部记录，无跳转箭头。
- 统计：按月/按年统计总睡眠时长、平均每天睡眠时长；入睡开始时间按凌晨（00–06）、上午（06–12）、下午（12–18）、晚上（18–24）统计次数，并以进度条显示。
- 导出：点击右下角按钮导出 JSON；长按按钮（桌面浏览器可右键）导入 JSON，导入会合并而非覆盖现有记录。
- 记录保存在当前浏览器 IndexedDB 本地数据库中。

## 安卓安装
1. 把项目文件部署到支持 HTTPS 的静态托管服务（例如 GitHub Pages）。
2. 用 Android Chrome 打开网页并从菜单选择“安装应用”或“添加到主屏幕”。
3. 首次在线打开完成缓存后，可离线启动和记录。

## 注意
- PWA 安装和 Service Worker 离线缓存需要 HTTPS 或 localhost；直接用文件管理器打开 index.html 不具备完整 PWA 离线能力。
- 数据只保存在当前浏览器/网站本地。清除网站数据、更换浏览器或设备可能丢失记录，请定期导出备份。
- 平均每天睡眠时长按所选月份/年份的自然日数计算。睡眠记录按开始日期归档，跨午夜时长会正常计算。
